# Value Filters

## Upper

Name: «name / upper»

## Lower

Name: «shouted name / lower»

## Truncate

- Shorter than the limit: «name / truncate: 10»
- Longer than the limit: «description / truncate: 10»
- Chained after join: «tags / join: , / truncate: 10»

## Default

- Unresolved: «nickname / default: N/A»
- Resolved: «other nickname / default: N/A»

## Symbols in filter value

«missing / default: a~b!c=d: e»
